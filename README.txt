BlockVerse 3D — نسخة تجريبية تعمل دون إنترنت
=============================================

التشغيل:
1) فك ضغط ملف BlockVerse-3D-Offline.zip.
2) افتح BlockVerse3D/index.html باستخدام Chrome أو أي متصفح حديث.
3) لا يلزم اتصال بالإنترنت أو تثبيت مكتبات خارجية.

المزايا:
- واجهة عربية متجاوبة.
- عالم مكعبات بمنظور إيزومتري ثلاثي الأبعاد مرسوم على Canvas.
- بلوكات برمجية يمكن إضافتها بالنقر أو السحب والإفلات.
- تشغيل الأوامر لتحريك الشخصية والقفز والاستدارة وجمع الموارد والزراعة والبناء.
- تقدم ونقاط خبرة ومهام تجريبية.

ملاحظة مهمة:
هذه نسخة أولية تعمل بالكامل محليًا. العالم مرسوم بمحرك Canvas إيزومتري خفيف، وليس محرك 3D كاملًا مثل WebGL/Three.js؛ لكنه لا يحتاج إلى الإنترنت أو ملفات خارجية.
