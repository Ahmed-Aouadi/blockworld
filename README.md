# 🧱 BlockWorld — بلوك وورلد
عالم ثلاثي الأبعاد للأطفال: ابنِ، استكشف، وتعلّم البرمجة بالبلوكات مع أصدقائك.

## التشغيل
1. ثبّت Node.js 18 أو أحدث.
2. داخل المجلد شغّل: `node server.js`
3. افتح http://localhost:3000 — أنشئ حسابًا وابدأ. لعب أصدقائك على نفس الشبكة عبر `http://عنوان-جهازك:3000`.

للعب عبر الإنترنت انشر المجلد على أي استضافة Node.js (Render, Railway, VPS…) — لا توجد مكتبات تُثبَّت.

## الهيكل
- `server.js` — حسابات (تشفير scrypt)، حفظ، لاعبون متصلون، دردشة، إهداء العناصر. البيانات في `data.json`.
- `public/js/catalog.js` — كتالوج العناصر وعناصر البناء.
- `public/js/world.js` — العالم ثلاثي الأبعاد والتحكم والبناء.
- `public/js/code.js` — البلوكات البرمجية والمفسّر والبلوكات المخصصة.
- `public/js/net.js` و`main.js` — الاتصال والواجهة.
